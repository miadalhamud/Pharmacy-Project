# Pharmacy Management System

A C++ project developed for the **Data Structures course**.

## Project Description

This project is a simple pharmacy management system that simulates a pharmacy with multiple branches. Each branch contains several pharmacists and medicines.

The system includes features such as:
- Managing pharmacy branches
- Managing pharmacists and medicines
- Customer points after purchases
- Additional rewards for pharmacists based on their sales

## Data Structures Used

The project demonstrates the implementation and use of:

1. **Linked List**
2. **Stack**
3. **Queue**

## Project Files

- `Linked List.cpp` – Linked List implementation
- `Stack.cpp` – Stack implementation
- `Queue.cpp` – Queue implementation
